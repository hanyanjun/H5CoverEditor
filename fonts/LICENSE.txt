合规要点(本项目):
- 本项目**未经任何修改**直接使用上述字体文件,未生成衍生字体。
- UI 中的字体名称(如"苹方"、"PingFang SC")仅是显示用标签,**未**作为
  衍生字体名使用,因此不触发 OFL Reserved Font Name 条款。
- 真实字体身份在 UI 中可见,用户与审计方均可直接核对。
- 字体通过 npm 依赖(@fontsource/*)分发,版本在 package.json 中**精确锁定**
  (无 ^ 范围),避免供应链自动升级引入未经审计的版本。
- 以下 3 个依赖均锁定在 5.3.0:
    @fontsource/noto-sans-sc    5.3.0
    @fontsource/noto-serif-sc   5.3.0
    @fontsource/inter           5.3.0
